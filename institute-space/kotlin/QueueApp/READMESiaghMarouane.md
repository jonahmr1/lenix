# QueueApp - La Poste Algerienne

A mobile queue management app for La Poste Algerienne built with Kotlin and Jetpack Compose.

## How to run

1. Open Android Studio
2. Open the project folder
3. Wait for Gradle to sync
4. Click Run or press Shift+F10

## Requirements

- Android Studio Hedgehog or newer
- Minimum SDK : API 24
- Kotlin

## Screens

- Home Screen : choose a service
- Ticket Screen : view your ticket
- Queue Screen : view the waiting list
